# FKG Reader

[English](README.md) | [简体中文](README.zh-CN.md)

用于在本地浏览、阅读 FLOWER KNIGHT GIRL 兼容剧情数据的非官方阅读器。

**本仓库只包含程序，不包含游戏剧情、译文、图片、音乐、语音、视频或游戏数据目录。程序不会自动获取这些内容。** 使用前，请自行确认你对相关数据具有合法的获取及使用权限。项目与游戏权利人、开发方及运营方没有官方隶属、合作或授权关系。

## 功能

- 按分类、章节或角色浏览剧情，支持搜索与收藏。
- 日文、中文和双语阅读，可交换双语左右位置；显示能力取决于本地数据是否含对应文本。
- 对话历史、已有语音重播、手动已读标记和自动保存阅读位置。
- 在有对应资源时显示背景、人物立绘、头像、卡片图片及本地视频，并播放 BGM、语音和音效。
- 调整字号、对话框高度与透明度、各类音量和人物显示位置；也可暂时隐藏文本框。
- 自定义名词译法、修改本地译文。个人修订与默认内容分开保存。
- 界面可切换中文或 English；原有日文标题不会因此被替换。

本程序使用简化的剧情演出，并不完整复现原游戏。互动小游戏不能在本程序中运行；视频是否带字幕取决于文件本身。图片中的文字须有兼容的识别文本才可显示文字译文，程序不会自动识别或翻译。

## 开始使用

### 1. 准备程序

下载本仓库源码（Code → Download ZIP，或克隆仓库）。如使用 ZIP，请完整解压到有写入权限的文件夹，不要直接在压缩包内运行。

**Windows 10/11** 下，`Start Reader.cmd` 会先查找可用的 Python 3.10+ 或已准备好的本地环境。如果没有，会在征得确认后从 `www.python.org` 下载官方运行环境，按固定 SHA-256 校验后放入 `runtime/`。仅首次准备时需要联网；不要求管理员权限、不修改 PATH，也不向系统安装 Python。后续启动复用已有环境，不重复下载。

也可拒绝下载并自行安装 [Python 3.10 或更高版本](https://www.python.org/downloads/)。其他系统需手动安装 Python，并确认终端可运行 `python` 或 `python3`。本项目仍以源码形式提供，不捆绑运行环境；仅使用 Python 标准库，无需安装额外 Python 包。阅读界面在浏览器中打开。

### 2. 放置本地数据

将你有权使用、且格式与本程序兼容的数据放入程序根目录的 `content` 文件夹。目录应如下所示：

```text
FKGReader/
├─ Start Reader.cmd
├─ Stop Reader.cmd
├─ Check Files.cmd
├─ app/
├─ runtime/                 # 仅在需要准备本地 Python 时创建
├─ content/
│  ├─ manifest.json
│  ├─ catalog/
│  ├─ stories/
│  ├─ dates/
│  ├─ translations/
│  ├─ glossary/
│  └─ assets/
└─ userdata/                # 使用过程中保存个人文件
```

请确认实际存在 `content/manifest.json`，不要多套成 `content/content/manifest.json`。单个 `.bin`、任意文件夹或游戏原始目录不能直接替代兼容的数据结构。程序文件夹本身不包含可阅读的剧情；未放置数据时会显示缺少本地数据的提示。

### 3. 启动和停止

Windows 下双击 `Start Reader.cmd`。程序准备好后会打开浏览器，地址为：

```text
http://127.0.0.1:8765
```

页面只连接本机服务，不需要游戏账号，也不需要在阅读时连接游戏服务器。关闭网页不会停止后台服务；结束使用后可双击 `Stop Reader.cmd`。

`Stop Reader.cmd` 和 `Check Files.cmd` 只复用已有环境，不会发起下载；缺少环境时，请先运行 `Start Reader.cmd`。准备 Python 的过程不会下载任何游戏数据或译文。

如果手动安装了 Python，也可在源码根目录从终端启动、停止（若系统使用 `python3` 或 `py -3`，请相应替换命令中的 `python`）：

```sh
python -B app/launcher.py
python -B app/launcher.py --stop
```

如果提示端口被另一份程序占用，请先停止另一份阅读器。不要同时启动多份；也不要为了继续阅读随意更换访问地址或端口。

## 阅读操作

打开 Library／剧情目录后，选择分类、章节或角色，再打开具体剧情。搜索兼容平假名、片假名和半角假名。

点击背景、人物或对话框可继续下一句，也可按空格或右方向键。History／历史可回看已浏览的对话；有可用语音的记录会显示重播按钮。阅读位置自动保存，但已读标记须手动设置。

在 Reading settings／阅读设置中调整语言、字号、对话框、音量和立绘。Hide text／隐藏文本可暂时只看背景和人物；恢复显示的第一次点击不会跳过台词。

只显示日文时不会显示译文编辑入口。显示中文或双语时可使用 Edit translation／编辑译文；修改以独立的个人修订保存，不会覆盖默认文本。Glossary／个人译法可修改已关联名词的译法，不会自动替换任意相似文字，也不会自动翻译缺少译文的内容。

如果声音没有播放，请检查声音总开关及对应音量。浏览器可能需要你先点击页面，才允许播放声音；没有本地音频文件时无法播放对应声音。

## 保存与备份

保存位置分为两类：

- **程序目录中的个人文件**：手动修订的译文在 `userdata/personal-translations.json`；运行日志也在 `userdata`。个人译文可通过界面的导入、导出功能备份。
- **浏览器本地存储**：阅读位置、History、已读标记、收藏、个人译法、玩家名称及显示和音量设置。它们不在 `content` 中。

请使用同一浏览器、同一浏览器配置及 `http://127.0.0.1:8765`。`localhost`、其他端口及隐私窗口会使用不同的存储。清除网站数据可能丢失浏览器记录；复制程序文件夹不会同时复制这些记录。目前没有整套浏览器记录的一键迁移功能。

“重置所有阅读进度”会清除阅读位置与对应历史，但不清除手动已读标记、收藏和个人设置。更新文件前请停止程序、备份 `userdata` 并保留浏览器数据。

## 替换程序或数据

程序文件与 `content` 相互独立。替换程序时保留自己的 `content` 和 `userdata`；整理或替换本地数据时，不要覆盖 `userdata`。不要删除整个 `content` 后只放入一小部分新增文件。

本程序没有联网更新、自动下载游戏内容或导入任意 ZIP 的功能。默认译文须与原文身份及内容校验相符；不匹配时会退回日文，不应强行修改校验字段套用旧译文。

`Check Files.cmd` 默认只核对程序文件。如需同时核对本地数据，可在 PowerShell 中运行 `& ".\Check Files.cmd" --include-content`。手动安装了 Python 时，也可在程序目录运行：

```powershell
python -B app/verify-release.py --include-content
```

若系统使用 `python3` 或 `py -3`，请相应替换命令中的 `python`。数据量较大时检查需要一些时间。校验仅检查文件与清单的一致性，不证明数据来源、真实性、完整程度或使用许可。

## 常见问题

**提示缺少本地数据**：检查 `content/manifest.json` 和 `content/catalog`，并确认没有多套一层目录。仅下载程序不能直接阅读剧情。

**没有中文或双语内容**：对应剧情需要有匹配的本地译文。程序本身不附带译文，也不会自动生成翻译。

**缺少图片或声音**：相应资源可能不存在、格式不兼容或引用不匹配。可在 Assets／素材面板查看缺失项目；程序不会自动联网补充。

**看不到以前的记录**：先确认浏览器、浏览器配置、地址和端口是否与之前相同；不要立即清理网站数据。

**Python 准备失败或取消**：未通过校验的下载不会执行。请检查能否访问 `https://www.python.org/`、目录是否可写，再重试；也可手动安装 Python 3.10+。不要关闭证书检查、杀毒软件或系统安全策略。本地环境准备完成后可离线使用，它不包含在源码下载中。

**启动失败**：检查源码是否完整解压、目录是否可写、是否有兼容的 Python 环境，以及是否有另一份阅读器占用端口。更多错误信息可查看 `userdata/logs`。反馈问题时请说明操作步骤和错误信息，不要附上完整剧情数据、账号信息或个人记录。
